# Snackautomat

Flutter-Starterprojekt für Windows. Der Einstiegspunkt ist `lib/main.dart`.

## Lokal starten

Du brauchst das Flutter SDK und Visual Studio mit der Workload
„Desktopentwicklung mit C++“. Mit `flutter doctor` kannst du die Einrichtung prüfen.

```powershell
flutter pub get
flutter run -d windows
```
